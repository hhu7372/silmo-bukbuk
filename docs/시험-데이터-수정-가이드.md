# 시험 데이터 수정 가이드

시간표, 과목, 문항 수, 파트(구간), 수능 방송 음원 연결은 모두 **`src/data/exams.json` 한 파일**에 있습니다.
코드는 건드리지 않고 이 파일만 고치면 웹사이트와 앱에 함께 반영됩니다. (앱은 웹사이트를 그대로 보여주는 방식이라 재심사 없이 바로 바뀝니다)

## 가장 쉬운 수정 방법 (GitHub 웹에서)

1. GitHub 저장소에서 `src/data/exams.json` 을 엽니다.
2. 오른쪽 위 연필(✏️ Edit) 버튼을 누릅니다.
3. 값을 고칩니다. (따옴표 `"`, 쉼표 `,` 를 지우지 않도록 주의)
4. 맨 위 `"updated_at"` 날짜도 바꿉니다.
5. **Commit changes** 를 누르면 몇 분 안에 자동 배포됩니다.

실수가 있으면 배포가 멈추고, 호스팅(Cloudflare Pages) 빌드 기록에 이런 식으로 이유가 나옵니다.

```
src/data/exams.json 에 고칠 곳이 있습니다:
- csat_standard › kor: 시작 08:40 ~ 종료 10:05 는 85분인데 duration_min 은 80 입니다.
```

이 경우 사이트는 **이전 버전 그대로 유지**되니 안심하고 다시 고치면 됩니다.

## 칸 설명

| 칸 | 뜻 | 예 |
| --- | --- | --- |
| `exam_id` | 시험 고유 이름 (바꾸지 마세요. 바꾸면 기존 기록과 연결이 끊김) | `csat_standard` |
| `edition` | 어느 해 기준 데이터인지 (홈 화면에 표시) | `2028학년도 수능 기준` |
| `category` | 분류: `csat`(대수능) / `cert`(자격증) / `civil`(공시) | |
| `popularity` | 분류 안 정렬용 연간 응시 규모 (대략, 만 명). 클수록 앞 | `200` |
| `notice` | 홈 화면 안내 문구 (선택) | |
| `adjustable_questions` | `true` 면 설정 화면에서 문항 수 조정 가능 | |
| `subjects[].id` | 과목 고유 이름 (기존 과목은 바꾸지 마세요) | `kor` |
| `start_time` / `end_time` | 시작·종료 시각 `HH:MM` | `08:40` |
| `duration_min` | 시험 시간(분). 종료 − 시작과 같아야 함 | `80` |
| `entry_deadline` | 입실 완료 시각 | `08:10` |
| `total_questions` | 문항 수 | `45` |
| `warning_min` | 종료 몇 분 전에 경고할지 | `10` |
| `sections` | 오답 분석용 파트 구간. 번호가 겹치면 안 됨 | `{ "name": "독서", "q_start": 1, "q_end": 17 }` |
| `electives` | 선택과목 (없으면 칸 자체를 지움) | |
| `short_answer_questions` | 단답형 문항 번호 (수학) | `[16, 17, …]` |
| `sub_modes` | 탐구 제1·제2선택처럼 시간대가 갈리는 경우 | |
| `sounds` | 시점별 내장 음원 파일. 시점: `yebi`(예비령) `prep`(준비령) `start`(본령) `warning`(종료 전) `end`(종료령) | `{ "start": "csat2019_kor_start_0840.mp3" }` |

음원 파일을 새로 넣으려면 `src/assets/sounds/` 폴더에 mp3 를 올리고 `sounds` 에 파일명을 적습니다. 파일이 없으면 기본 벨소리 + "본령입니다." 같은 짧은 안내로 재생됩니다.

## 2028학년도 수능(2027년 11월 시행) 개편 때 할 일

교육부 발표 기준으로 국어·수학 선택과목이 없어지고, 사회·과학 탐구가 통합사회·통합과학으로 바뀝니다.
**시험 시간·문항 수·파트 구분은 평가원 공식 발표(시행 기본계획)를 확인한 뒤** 아래처럼 고치세요.

1. `csat_standard` 의 `edition` 을 `2028학년도 수능 기준 (2027년 11월 시행)` 으로.
2. **국어 `kor`**: `electives`, `elective_label` 칸 삭제 → 선택과목 고르는 화면이 자동으로 사라짐. `sections` 를 새 구성(예: 독서/문학 범위)으로.
3. **수학 `math`**: `electives`, `elective_label` 삭제. `sections`, `short_answer_questions` 를 새 구성으로.
4. **탐구**: 기존 `sci`, `soc` 과목을 지우고 새 과목을 추가합니다. 새 과목은 **새 id** 를 쓰세요(예: `int_soc`, `int_sci`). 기존 `sci`/`soc` 기록은 누적 기록 화면에 "(이전 구성)" 으로 계속 남습니다.
   ```json
   {
     "id": "int_soc",
     "tab_name": "통합사회",
     "period": "4교시",
     "entry_deadline": "14:40",
     "start_time": "평가원 발표 시각",
     "end_time": "평가원 발표 시각",
     "duration_min": 0,
     "total_questions": 0,
     "warning_min": 5,
     "accent": "rose",
     "sections": [{ "id": "all", "name": "전 범위", "q_start": 1, "q_end": 0 }]
   }
   ```
   (`0` 과 "평가원 발표 시각" 은 자리표시입니다. 실제 값으로 바꾸지 않으면 검사에서 막힙니다)
5. `schedule_summary`(홈 화면 "전체 시간표 보기") 도 새 시간표로.
6. 내장 음원은 2019학년도 방송본이라 시각이 달라질 수 있습니다. 시점(본령·종료령 등)에 맞춰 그대로 재생되므로 보통은 그대로 둬도 됩니다.

## 새 시험 추가

`exams` 배열에 기존 시험 하나를 복사해 붙인 뒤 `exam_id` 를 새 이름으로 바꾸고 값을 고치면, 홈 화면 분류·설정·시험·채점·누적 기록이 모두 자동으로 동작합니다.
