# 플레이 스토어 등록 자료

이 폴더의 이미지는 실제 앱 화면(예시 데이터)으로 만든 스토어 등록용 자료입니다.

| 파일 | 용도 | 크기 |
| --- | --- | --- |
| `app-icon-512.png` | 앱 아이콘 | 512×512 |
| `feature-graphic-1024x500.png` | 그래픽 이미지(필수) | 1024×500 |
| `phone-1~4-*.png` | 휴대전화 스크린샷 | 810×1440 (9:16) |
| `tablet-1~4-*.png` | 7인치·10인치 태블릿 스크린샷 | 2560×1440 (16:9) |

태블릿 스크린샷을 올려야 스토어에서 "태블릿용" 앱으로 노출됩니다. 7인치·10인치 칸 모두에 `tablet-*.png` 를 올리면 됩니다.

## 앱 만들기 (PWABuilder, 코딩 없음)

1. 사이트가 내 도메인(https)으로 배포된 상태여야 합니다.
2. https://www.pwabuilder.com 에 사이트 주소를 넣고 **Start** → **Package For Stores** → **Android** → **Generate Package**.
   - Package ID: `kr.silmobukbuk.app` (한 번 정하면 못 바꿈)
   - App name: `실모벅벅 - 모의고사 타이머`, Short name: `실모벅벅`
   - Signing key: **Create new** (자동 생성)
3. 내려받은 zip 안의
   - `*.aab` → 플레이 콘솔에 올릴 앱 파일
   - `signing.keystore` 와 `signing-key-info.txt` → **절대 잃어버리면 안 되는 서명 키**. 클라우드·USB 두 곳 이상에 보관
   - `assetlinks.json` → 안의 `package_name` 과 `sha256_cert_fingerprints` 값을 호스팅 환경 변수에 넣습니다:
     - `TWA_PACKAGE_NAME` = `kr.silmobukbuk.app`
     - `TWA_SHA256_FINGERPRINTS` = 지문 (플레이 콘솔 **앱 무결성 → 앱 서명**의 SHA-256 지문도 쉼표로 이어서 추가)
   - 다시 배포하면 `https://내도메인/.well-known/assetlinks.json` 이 생깁니다. 이 파일이 있어야 앱 위쪽에 주소창이 안 보입니다.

## 앱 콘텐츠 설문 답변 가이드

| 항목 | 답변 |
| --- | --- |
| 광고 포함 | 광고를 붙였으면 "예", 아니면 "아니요" |
| 앱 액세스 권한 | 모든 기능 제한 없이 사용 가능 (로그인 없음) |
